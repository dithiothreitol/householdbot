# Chain seams — what breaks between skills

Some defects exist in no single skill. They appear where one skill hands
something to another, or where a skill promises something that happens later.

---

## 1. A handoff carries its source

When `file-document` hands an obligation to `deadline-tracker`, or
`weekly-brief` lists what `deadline-tracker` reports, the entry crosses with
its id, its `provenance` and its source. A date that was
`model calculation — verify` on one side does not become a plain date on the
other. A figure that described one bill does not become the month's total.

**The rule.** Pass ids and register entries between skills, not retyped
values. When a value must be restated, restate its tag with it.

## 2. A cadence nobody set

Saying "I will send you this every Monday" stores nothing and wakes nothing.

**The rule.** Never tell the household a schedule is set unless something was
actually scheduled.

- **Where the environment offers real scheduled tasks** (for example a
  scheduled task in Cowork or Claude Code), create one only after a yes, and
  confirm what it will do and when: *"Set. Mondays at 7:00, and it will
  appear in this app."*
- **Where it does not**, say so plainly and offer the honest substitute: a
  recurring calendar entry that reminds a member to ask for the brief, created
  only after a yes.
- **Save the preference either way** in the profile's *Rhythm* section. That
  part does work.

## 3. Times that are wrong by hours

Calendar events carry offsets; a calendar's default zone is where the account
was created, not where the household lives.

**The rule.** Use the profile's `Time zone`. Trust the offset in a timestamp
over a zone label beside it. Print the time in the household's zone, and name
the zone when anyone outside the household is involved. When the signals
disagree, say so rather than picking.

## 4. A suggested slot is not a free slot

A scheduling tool can report a day as free when it is not. Before proposing a
time, read the actual events for that day.

## The shared shape

Before passing anything across a seam, ask what it measured and whether the
receiving skill measures the same thing. When the answer is no, the value
crosses as labelled context, never as an input to arithmetic.
