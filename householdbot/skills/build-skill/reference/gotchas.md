# Gotchas — build-skill

- **Do not re-interview about a task just done.** When the member walked
  through it in this conversation, restate it and ask "Is that it?"; their
  corrections are the skill's rules.
- **Do not hardcode the example.** November's readings, this month's amount
  and last Tuesday's letter are inputs; the order of the steps and the rules
  are the skill.
- **A reminder is not a skill.** A date that repeats belongs in
  `deadline-tracker`. Build a skill for a task with steps.
- **Look on the shelf first.** A HouseholdBot skill that already does the
  task beats a new one; a duplicate competes with it for the same phrases.
- **Gate what matters, not everything.** Reading, counting and drafting run;
  writing, sending and paying wait for a yes. A skill that asks nine times is
  slower than doing the task by hand, and nobody runs it.
- **A vague gate is no gate.** "Ready?" approves nothing. The question says
  what will be written or sent, where, and to whom.
- **"Pay it automatically" gets a payment list.** The built skill prepares the
  amount, the payee and the date; the member pays in their bank. "Send it"
  gets a draft the member sends.
- **Secrets never go in.** A PIN, a password or a code typed in the request is
  not repeated and not written, not even as an example.
- **Numbers live on the paper.** Account, customer, meter and policy numbers
  are named by document and page, at most the last four digits.
- **Outsiders by role.** The cooperative's clerk, the landlord, the teacher:
  a role in the skill, never a name. The household's own first names are fine.
- **One skill, one task.** "All of our month-end" is three skills; start with
  the part that takes longest.
- **Installing over an existing skill is overwriting it.** Show the
  difference first; a different skill with the same name gets another name.
- **The household's words, not office words.** If they say "liczniki", the
  skill says "liczniki"; a skill in someone else's vocabulary is not trusted.
