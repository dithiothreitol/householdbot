# Gotchas — health-file

- **The title is read by everyone.** A register title, a reminder and a
  calendar entry are seen far beyond the person; "Referral, Zosia" says
  enough.
- **Valid from is not issued on.** A prescription may name a later date from
  which it can be filled; the window counts from that date, as the pack says.
- **One window does not fit every paper.** Antibiotics, imported medicines and
  long-term prescriptions have their own periods in the pack; never apply the
  general one by default.
- **A referral is not an appointment.** Registering on a waiting list may set
  its own steps; the pack says which.
- **Results are not explained.** Ranges, flags and "is this bad" belong to the
  doctor; say so in one line and offer to note the question for the visit.
- **Another adult's papers are theirs.** A spouse asking about the other
  spouse's results gets "ask them", not the results.
- **The code stays on the paper.** E-prescription and e-referral codes are
  handed over at the pharmacy or clinic from the paper or the app, never
  copied into the record.
- **Look before asking for the paper.** In testing, a request to register a
  referral that was already filed got a request for the file. Search the
  register first; offer only what is missing.
