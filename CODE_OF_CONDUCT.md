# Code of Conduct

HouseholdBot adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

Everyone who takes part in issues, pull requests and discussions is expected
to follow it. To report unacceptable behaviour, use GitHub's *Report content*
option on the comment, issue or pull request; when personal data is involved,
open a private security advisory instead. Reports are handled confidentially.
